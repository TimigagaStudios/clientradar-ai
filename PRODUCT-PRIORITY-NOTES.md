# Lead priority and launch-readiness update

Base: GitHub main 3a1820d4f12370c0b7ae1577ba26b6e7a7100c4e (round 7 merged). Upload all package paths to one branch; no migration or new service is needed.

Qualified Lead Finder results with no website listed now appear first. Lead Research and proposed Team demo batches similarly prioritize prospects with no saved website and both email and phone in plausible formats. Other candidates remain available. Existing order is preserved within priority groups. Batch and Autopilot selection still considers at most the existing 400 top-scored saved leads, so the priority is not guaranteed across the whole database. The existing explicit no-website batch filter selects database NULL, not blank strings. Research uses existing fetched results and request bounds; it does not make extra provider requests. None of this verifies contact ownership, reachability, consent or whether a website exists. Scans and provider costs already present are unchanged. Demo creation and outreach approvals are unchanged.

Checks: 25 offline regression suites passed, including synthetic research and Team staging with no real demos or emails. Targeted server TypeScript passed and client TypeScript matched the 17 existing baseline diagnostics. An actual-component mocked Lead Finder fixture passed Chromium and WebKit at widths 390, 768 and 1280 for ranking, page overflow and errors. The real map worker, live providers, physical devices and the production app were not tested. A new production Vite build was not completed locally; the round-7 Vercel production deployment succeeded, but this package needs its own Vercel build and real-device verification.

Pricing remains industry-independent in the existing app; internal estimates are not customer-approved quotes and currently vary by priority, score and missing website. Do not use the estimate as an approved price. Different industry prices and demo scope require an owner decision. New demo default remains Ultra Premium; explicit lower tiers remain possible. No real outreach, demo, database update or provider lookup was performed during testing.

Launch warning: some existing Leads/Lead Detail screens generate an AI-labeled star-like rating when a real rating is missing and use a default rating component in lead scoring. Lead Detail also contains unsupported fast-turnaround and performance language in a local summary. These pre-existing behaviors were found in review and are not fixed by this package. Treat them as data-honesty issues to address before relying on those ratings or sharing the summary. Production stability, deliverability, customer readiness and revenue cannot be certified by these tests.
